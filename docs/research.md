# Competitive Research

## 1. WhatsApp Student Groups — The Current Direct Workaround

| Dimension | Analysis |
| :--- | :--- |
| **Who it is for** | ASU students seeking quick lecture updates or peer help. |
| **What it does well** | Near-universal adoption; almost every student is already on WhatsApp, so there is no onboarding barrier. |
| **What it misses** | High-volume, unstructured traffic. Study group requests, academic questions, and schedule coordination are buried within minutes under hundreds of casual messages. The resulting information overload raises the social cost of reaching out, particularly for introverted students. |
| **What it costs** | Free. |

## 2. Bumble BFF — The Mobile Benchmark

| Dimension | Analysis |
| :--- | :--- |
| **Who it is for** | General users seeking platonic friendships based on lifestyle tags. |
| **What it does well** | A strong, memorable card-stack interface, structured profile prompts, and built-in safety verification. |
| **What it misses** | A generic, global mobile product. It has no awareness of university faculties, buildings, or class schedules, so it cannot match students by shared campus location or overlapping free blocks. It also has no student-only gate to keep non-students out of a campus circle. |
| **What it costs** | Free, with paid premium tiers. |

## 3. Tinder — The Casual Swipe Paradigm

| Dimension | Analysis |
| :--- | :--- |
| **Who it is for** | A general mainstream audience seeking immediate social connections. |
| **What it does well** | Fast, responsive swipe mechanics and an immediate, gamified feedback loop. |
| **What it misses** | Built around dating dynamics, which creates friction for students seeking platonic study partners. Matching is driven by geographic proximity and displayed distance to unverified strangers, which raises privacy and safety concerns in shared public spaces. It carries no academic context: no majors, courses, or schedule overlap. |
| **What it costs** | Free, with paid upgrades. |

## Why Anyone Would Use Campus Buddy Instead

Campus Buddy is the only option that pairs Bumble BFF's platonic card-swipe mechanics with a strict `@students.asu.edu.jo` email authorization gate, block-based timetable overlap scoring, and fixed ASU landmark meeting points, so every mutual match arrives with a verified campus identity, a shared free window, and a place to meet, eliminating the early-stage chat fatigue that WhatsApp groups and general-purpose swipe apps create.
